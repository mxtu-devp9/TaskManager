# 📋 TaskManager

A modern **Task Management** application built with **SwiftUI** following the **MVVM architecture**. The app enables users to create, manage, update, and delete daily tasks through a clean and intuitive interface while demonstrating SwiftUI best practices, reactive UI updates with Combine, and a scalable project structure.

---

## ✨ Features

- ✅ Create new tasks
- ✏️ Edit and update tasks
- 🗑️ Delete tasks
- 📋 View all tasks in a clean list
- 🔄 Reactive UI using SwiftUI & Combine
- 🏗️ MVVM Architecture
- 📱 Native iOS User Experience

---

## 🛠️ Tech Stack
