# TaskManager
A SwiftUI Task Management application built using MVVM architecture with task creation, completion, deletion, and reactive UI using Combine.

TaskManager – SwiftUI Task Management App

A modern task management application built with SwiftUI following the MVVM architecture. The app provides a clean and intuitive interface for creating, managing, and organizing daily tasks while demonstrating SwiftUI best practices and state management.

Features
✅ Create new tasks
✏️ Update task status
🗑️ Delete tasks
📋 View all tasks in a clean list
🔄 Reactive UI using SwiftUI
🏗️ MVVM architecture
📱 Native iOS user experience
